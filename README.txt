---------------------------------------- ¡IMPORTANTE! --------------------------------------

Adjunto la carpeta del proyecto, la documentación y el ejecutable .jar para que pueda desplegar en local la pagina y probarla.

En esta versión, al ejecutarse en tu propia máquina, los chats no serán en tiempo real a menos que los dos clientes sean de la misma. En el caso de que tenga un servidor local para alojarla, olvida esto.

Además, al no tener el modelo de IA descargado en tu máquina, estará desactivada esta funcionalidad.

Por último, para la implementación de está página se ha utilizado la versión de java 21.0.8+9 ( Temurin 21). Dejo aquí dicha versión para descargar por si es necesario. 

https://github.com/adoptium/temurin21-binaries/releases/download/jdk-21.0.8%2B9/OpenJDK21U-jdk_x64_linux_hotspot_21.0.8_9.tar.gz
